# Ankush Dubey — Refined Professional Portfolio

A responsive, dark-premium portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html`, or run `python -m http.server 8080` and visit `http://localhost:8080`.
